# TURTO – Databáze izolačních nosníků

Distribuce aplikace pro vyhledávání statických hodnot izolačních nosníků.

## Instalace

1. Stáhněte tuto větev jako ZIP (**Code → Download ZIP**).
2. ZIP rozbalte do běžné složky ve Windows.
3. Spusťte `Instalovat_TURTO.vbs`.
4. Instalátor vytvoří složku `TURTO_Izolacni_nosniky` a program spustí.

Při prvním spuštění si aplikace z kompaktních seed dat lokálně vytvoří katalogovou databázi. Trvá to obvykle jen několik sekund.

## Aktualizace

V aplikaci je tlačítko **Aktualizace**. Program stáhne kompaktní aktualizační balíček z této větve, ověří SHA-256 a nahradí pouze programová/seed data. Rozbalená lokální databáze se znovu vytvoří pouze tehdy, když se katalogová data změnila.
