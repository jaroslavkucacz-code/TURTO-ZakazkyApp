TURTO – Měsíční přehledy 1.0.1

Tato verze používá standardní instalaci Windows bez administrátorských práv.

Program:
%LOCALAPPDATA%\Programs\TURTO Mesicni Prehledy

Uživatelská data:
%LOCALAPPDATA%\TURTO\MesicniPrehledy

Databáze, config.json, importy, exporty a zálohy jsou uloženy mimo instalační složku programu. Odinstalace aplikace je proto nemaže.

Při online přechodu ze starší verze 0.2.8 se stávající data automaticky překopírují do nové datové složky. Pokud tam už nějaký soubor existuje, migrace jej nepřepisuje.

Program se spouští jako TURTO_Mesicni_Prehledy.exe. Python není pro běžný provoz potřeba.
