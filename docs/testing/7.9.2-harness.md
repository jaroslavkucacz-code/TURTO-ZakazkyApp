# Test harness corrections for 7.9.2

The navigation test now runs the actual runtime_bootstrap. The older 7.1 and 7.2 source-contract tests consequently check that bootstrap is called and that their respective layer remains registered, instead of requiring the abandoned inline apply calls. Their functional assertions remain enabled.

Windows Calibri PDF extraction maps some spaces to NBSP and ASCII hyphens to U+2010. The new PDF test normalizes only these typographic glyphs before comparing text and document-number rectangles. It still requires exactly one number in the header, preserved technical text and no labeled purchase-price amount.

The 7.4 test database used raw sqlite3.Connection context managers, which commit or roll back without closing the Windows file handle. Its fixture now closes in a finally block. The production database factory is not patched.

Unexpected modal questions in the full template integration test now produce an explicit test failure rather than waiting for human input. A periodic traceback documents any remaining timeout. No production modal question is automatically accepted by these diagnostics.
